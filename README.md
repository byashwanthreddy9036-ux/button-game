# Button Game

A button that dodges your cursor (or finger, on touch devices) — click anywhere else and it
counts as a miss; actually land on the button to win.

## Features

- Button dodges on hover (mouse) or touch, moving to a random spot on screen
- Miss counter (clicks that land anywhere except the button)
- Win counter and a best (fewest-misses-to-win) score, both persisted in `localStorage`

## Run locally

Open `index.html` in a browser, or serve the directory with any static file server.

## Deployment

Fully static — deploys to Vercel, Netlify, GitHub Pages, or any static host with zero
configuration.
